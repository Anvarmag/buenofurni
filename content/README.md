# Контент buenofurni — рабочая папка

Здесь живёт **исходный материал** для статей, посадочных и текстов сайта, и **готовые черновики**. Это не то, что напрямую показывается на сайте — это «кухня», из которой рождается контент. Готовый контент потом переносится в код сайта (блог/посадочные).

## Как это работает

```
content/
├── README.md          ← этот файл
├── reference.md       ← СПРАВОЧНАЯ: единый источник фактов о компании (заполняешь ты)
├── inbox/             ← сюда ты кладёшь СЫРЬЁ для статей
│   └── EXAMPLE.md     ← пример, как оформить материал
├── articles/          ← сюда я пишу ГОТОВЫЕ статьи (черновики)
│   ├── _template.md   ← шаблон статьи (структура «под ИИ-ответ»)
│   └── IDEAS.md       ← план тем (бэклог статей)
```

## Твой шаг

1. **Заполни `reference.md`** реальными фактами (цены «от», сроки, материалы, гарантия, адрес). Это критично — из него берутся все цифры и факты, чтобы ничего не выдумывать.
2. **Кидай материал в `inbox/`** — в любом виде: текст, заметки, ответы на вопросы, ссылки на фото, голосовые расшифровки. По одному файлу на тему/статью. Как оформить — смотри `inbox/EXAMPLE.md` (но строгого формата нет, главное — факты).

## Мой шаг

- Беру материал из `inbox/` + факты из `reference.md`.
- Пишу статью по шаблону `articles/_template.md` (с блоком «Коротко:» для ИИ-выжимки и «Частые вопросы» для FAQPage-разметки).
- Кладу готовый черновик в `articles/`, ты проверяешь.
- После твоего «ок» — переношу в код сайта (блог-роут + JSON-LD).

## Правило №1

**Ничего не выдумываем.** Цены, сроки, материалы, гарантии, год, адрес — только реальные из `reference.md`. Чего нет — пишем «уточнить», а не сочиняем.
